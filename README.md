# Proiect Unity
Proiect pentru materia "Introducere in Dezvoltarea Jocurilor pe Calculator" 

## Nume joc: Survival Master 

## Premiza:
Un joc survival bullet hell cu cameră izometrică, în care joci împotriva unor valuri nesfârșite de inamici într-o lume ostilă și decăzută. Armele atacă automat, tu doar te miști, te ferești și iei decizii: ce arme alegi, ce clădiri riști să explorezi, ce resurse păstrezi și când te retragi. Fiecare rundă este o poveste mică de supraviețuire, scurtă, intensă și diferită de precedenta.
